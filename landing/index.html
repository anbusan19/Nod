Nod lets you decide how your agents move money.

The agent proposes. It never signs.

Any script or bot sends Nod a Solana transaction and a one-line reason, through a small SDK or plain HTTP. It holds an API key you can revoke, never the key that moves funds.

Connect an agent → 
$ nod.propose({
  agent:  "demo-agent",
  reason: "Weather API credits",
  tx:     "AQAAAAAA…"  // 0.05 SOL
})

Sent. Waiting for the owner's Nod.

Your phone reads what it really does.

The app decodes the transaction itself and simulates it locally. What the agent claimed is compared with what the transaction does, and a mismatch is flagged before you ever reach an approve button.

  • Balance before and after, simulated on the device
  • A countdown, and a fresh check if the quote goes stale

You set the limits. Nod enforces them.

Auto-approve small payments to recipients you allowed, require your Nod for the rest, and block anything over the hard cap. A daily cap and a one-tap freeze sit on top.

  • Per-agent limits, set in the app
  • Allowed recipients and a daily spend cap
  • Freeze an agent or revoke its key at any time

For developers

Connect any agent in a few lines.

Run your own backend with one command, pair your agent with a code from the app, and propose transactions through a small SDK or plain HTTP. Nothing is locked to a hosted service.

  • npx nod-server starts a backend with its own data folder and secret
  • --tunnel gives it a public https address through your own cloudflared or ngrok
  • Retry-safe proposals, an OpenAPI spec, and a conformance suite for other implementations
agent.ts 
# run your backend
npx nod-server --tunnel
 
// propose a payment from your agent
const nod = new Nod({ apiUrl, agentKey });
const built = await transferSol({ connection, from, to, sol: 0.05 });
 
const result = await nod.proposeAndWait({
  ...built,
  reason: "Weather API credits",
});
 
// your phone buzzes; once you nod:
if (isConfirmed(result)) console.log(result.signature);
